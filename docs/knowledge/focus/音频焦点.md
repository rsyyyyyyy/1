# 音频焦点

## 范围

音频焦点负责协调多个播放和录制会话，包括中断请求、焦点持有、并发、闪避、暂停/停止决策、回调通知和恢复。

## 功能规格

- 注册和注销中断监听器。
- 根据流用途、内容类型、会话和应用信息请求或放弃焦点。
- 处理共存、暂停、停止、闪避和拒绝等结果。
- 通知客户端焦点变化，并支持客户端确认或恢复。
- 在功能开关允许时支持音区和场景相关策略。

## 约束

- 对同一组活动会话，焦点决策应保持确定性。
- 回调中的会话标识和应用身份不能混淆。
- 焦点状态与流生命周期变化必须保持一致。
- 过期回调不能重新唤醒已经停止或释放的流。
- 设备切换、服务重启和账户变化后必须重新评估焦点。

## 安全与隐私

- 特殊焦点请求必须校验调用方身份和用途权限。
- 不得向一个应用泄露无关应用的包名、会话和状态等非必要信息。
- 回调载荷只应包含接口契约要求的信息。
