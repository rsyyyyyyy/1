# 音频测试与故障诊断

## 测试层次

- Renderer、Capturer、音效、策略管理器和适配器原生 API 单元测试。
- 音频流管理生命周期、流创建、端点、缓冲区和回调测试。
- 音频策略设备、路由、音量、中断、会话、配置解析和恢复测试。
- N-API、C API、CJ、Taihe 和 OpenSL ES 绑定测试。
- IPC 入口、序列化对象、配置解析、回调、策略领域、缓冲区和引擎模糊测试。
- 时延、并发和线程安全相关的基准测试及多线程测试。

## 故障验证

- 恢复场景应覆盖服务死亡、设备断开、路由重建、端点释放、流恢复和蓝牙状态变化。
- 诊断数据用于验证状态转换与错误原因，其打点、权限和数据最小化要求见 [DFX.md](../dfx/DFX.md)。

## 测试不变量

- 每个生命周期操作都应覆盖非法状态和重复调用。
- 每个 IPC 方法都应覆盖空远程对象、非法输入和服务不可用。
- 每类设备事件都应覆盖连接、断开、变化和过期事件。
- 每条隐私敏感链路都应覆盖允许、拒绝、静音和权限撤销。
- 每个功能开关在可行时都应覆盖开启和关闭路径。
