# 音频编创

## 范围

音频编创聚焦 `audio_suite` 相关能力，包括面向调用方的套件接口、服务侧能力接入、配置和样例。它描述套件提供的音频创作或处理工作流，不泛指音频引擎、普通在线音效或所有音频变换。

## 设计规格

- 通过受支持的套件接口组织音频输入、处理配置和结果交付。
- 客户端、服务能力和底层处理能力之间通过明确的请求、状态和结果边界协作。
- 可选套件能力受构建配置、产品集成和运行时能力控制；能力缺失时应清晰失败或按契约降级。
- 套件处理与普通 Renderer/Capturer 生命周期保持边界清楚；若组合使用，应明确数据来源、会话归属和处理阶段。

## 约束与常见误区

- `audio_suite` 是本主题的主要范围；不要把文档重新扩展为通用音效或 audio_engine 处理说明。
- 不把可选套件能力写成所有产品默认启用的功能。
- 请求配置、输入输出格式、资源生命周期和异步结果必须保持一致。
- 失败、取消或服务退出后不得残留未释放的会话或缓冲区。
- 能力名称和行为以仓库当前接口、配置及服务实现为准，不从示例推导稳定承诺。

## 安全与隐私

- 处理前校验调用者授权、输入来源、参数范围和资源大小。
- 用户音频、生成结果及中间缓存均按敏感数据处理；不得写入未授权日志或持久化位置。
- 跨服务传输只携带完成请求所需的最小信息。
