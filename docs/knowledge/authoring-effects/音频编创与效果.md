# 音频编创与效果

## 范围

本主题中的“音频编创”指框架支持的音频创建和变换能力，包括音效、增强、重采样、声道转换、离线处理、提示音生成、音频套件和播放采集组合。

## 功能规格

- 对支持的音频流应用在线音效和增强链。
- 在 `audio_framework_feature_offline_effect` 开启时支持离线音效处理。
- 提供重采样、格式转换、声道转换、下混、限幅、音量渐变和静态缓冲区处理。
- 在功能开关允许时支持音频套件 API 和处理图。
- 转换过程中保持时间戳、帧位置、声道布局和流元数据。

## 约束

- 处理过程必须遵守格式、采样率、声道数、帧对齐和缓冲区所有权。
- 音效处理不能隐式改变流生命周期或策略状态。
- 可选引擎和插件必须提供基础降级路径。
- 实时路径应避免无界内存分配、阻塞 I/O 和不可预测时延。

## 安全与隐私

- 音效和增强属性传入引擎前必须校验。
- 禁止在日志中输出原始 PCM 和敏感音效元数据。
- 离线文件处理必须校验路径、权限、文件大小和格式。
- 插件边界属于信任边界，必须检查返回值和资源释放。
