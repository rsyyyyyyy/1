# 音频播放

## 范围

音频播放包括 Renderer 创建、流配置、输出路由、缓冲区提交、回调、时序、音效、卸载、低时延和释放。

## 功能规格

- 根据流用途和播放参数创建 Renderer。
- 配置采样格式、采样率、声道数、编码类型、声道布局和 Renderer 标志。
- 在功能开关允许时支持阻塞写、回调写、静态缓冲区、直通、快速和卸载播放。
- 提供启动、暂停、停止、排空、刷新、释放、位置、时延、音量、音效、变速、变调和设备变化能力。
- 通过回调通知状态、中断、位置、首帧、写入、错误和设备变化。

## 主要链路

`AudioRenderer` -> `AudioRendererPrivate` -> `RendererInClientInner` -> `AudioServer::CreateAudioStream` -> `IpcStreamInServer` 或 `AudioProcessInServer` -> `RendererInServer` / PulseAudio / HPAE / 专业音频流。

## 约束

- 转发前校验流用途、权限、Renderer 标志、格式、声道数、缓冲区长度和当前状态。
- 停止或释放后不能继续写入。
- 必须正确处理部分写入和背压，不能丢失调用方缓冲区所有权。
- 设备切换、服务死亡和恢复过程中必须保持会话标识一致。
- 卸载和低时延路径必须受功能开关和设备能力约束。

## 安全与隐私

- 系统流、DTMF、强制提示音和超声波等特殊用途必须进行权限校验。
- 禁止记录 PCM 内容、应用令牌和原始设备信息。
- 静态缓冲区、共享内存和元数据必须按不可信输入校验。
- 服务死亡后应失败关闭，并通过受控流程重新创建或恢复。
