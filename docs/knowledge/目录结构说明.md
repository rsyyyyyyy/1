# 音频框架目录结构说明

下表说明本仓库主要目录及其子目录职责。测试模糊目标数量较多，按目标族归纳；每个具体模糊测试目录通常都包含独立的 GN 目标、测试入口和可选工程元数据。

## 根目录

| 目录 | 简要说明 |
| --- | --- |
| `.gitee/` | 仓库贡献流程和平台服务配置。 |
| `figures/` | 架构图和文档图片。 |
| `frameworks/` | 面向客户端的框架实现和语言绑定。 |
| `interfaces/` | 公共 Kit 和内部 API 声明。 |
| `plugins/` | 跨平台或产品适配插件。 |
| `sa_profile/` | 音频系统能力注册配置。 |
| `services/` | 音频策略、音频服务、音频引擎和音频套件。 |
| `test/` | 示例、模块测试、单元测试、基准测试和模糊测试。 |

## frameworks

| 目录 | 简要说明 |
| --- | --- |
| `frameworks/cj/` | CJ 语言 FFI 实现；`include/` 放导出声明，`src/` 放绑定实现。 |
| `frameworks/js/` | JavaScript/N-API 实现；`napi/` 包含 Renderer、Capturer、Manager、Loopback、回调和参数绑定。 |
| `frameworks/native/` | 原生 C++ 框架实现。 |
| `frameworks/native/audioadapter/` | 音频适配器抽象和适配辅助功能。 |
| `frameworks/native/audiocapturer/` | 原生录音 API 实现。 |
| `frameworks/native/audioclock/` | 音频时钟和时序支持。 |
| `frameworks/native/audiodefinitions/` | 原生公共定义和类型转换。 |
| `frameworks/native/audioeffect/` | 在线音效客户端 API 和接入。 |
| `frameworks/native/audioinnercall/` | 模块间内部音频调用。 |
| `frameworks/native/audioloopback/` | 回采和播放采集客户端支持。 |
| `frameworks/native/audiopolicy/` | 原生策略管理器客户端。 |
| `frameworks/native/audioqosmanager/` | 音频 QoS 和调度支持。 |
| `frameworks/native/audiorenderer/` | 原生播放 API 实现。 |
| `frameworks/native/audioschedule/` | 音频调度和性能协调。 |
| `frameworks/native/audiostream/` | 公共流抽象。 |
| `frameworks/native/audioutils/` | 转换、校验、日志和通用工具。 |
| `frameworks/native/bluetoothclient/` | 蓝牙音频客户端适配。 |
| `frameworks/native/examples/` | 原生使用示例。 |
| `frameworks/native/hdiadapter_new/` | 新版 HDI 音频设备适配层。 |
| `frameworks/native/offlineaudioeffect/` | 离线音效处理客户端。 |
| `frameworks/native/ohaudio/` | OH 音频 C API 实现。 |
| `frameworks/native/ohaudiosuite/` | 原生音频套件 API 实现。 |
| `frameworks/native/opensles/` | OpenSL ES 兼容实现。 |
| `frameworks/native/playbackcapturer/` | 播放采集客户端 API。 |
| `frameworks/native/pulseaudio/` | PulseAudio 模块和接入。 |
| `frameworks/native/toneplayer/` | 提示音播放实现。 |
| `frameworks/taihe/` | Taihe 绑定；包含 Renderer、Capturer、Manager、Loopback、ASR、公共代码、IDL 和源码生成接入。 |

## interfaces

| 目录 | 简要说明 |
| --- | --- |
| `interfaces/inner_api/` | 平台内部 API。 |
| `interfaces/inner_api/native/audiocapturer/` | 原生录音接口。 |
| `interfaces/inner_api/native/audiocommon/` | 音频公共类型、描述符、错误码和流定义。 |
| `interfaces/inner_api/native/audioloopback/` | 回采接口。 |
| `interfaces/inner_api/native/audiomanager/` | 系统、流、组、路由、音量和策略管理器接口。 |
| `interfaces/inner_api/native/audiorenderer/` | 原生播放接口。 |
| `interfaces/inner_api/native/audiosasdk/` | 音频系统能力 SDK 接口。 |
| `interfaces/inner_api/native/audiosuite/` | 音频套件接口。 |
| `interfaces/inner_api/native/offlineaudioeffect/` | 离线音效接口。 |
| `interfaces/inner_api/native/toneplayer/` | 提示音接口。 |
| `interfaces/kits/` | 面向应用的公共 Kit。 |
| `interfaces/kits/c/` | Renderer、Capturer、Manager、Suite 和公共类型的 C API 头文件。 |

| `services/audio_engine/utils/` | 引擎内部工具。 |
| `services/audio_engine/test/` | 引擎单元测试和测试资源。 |
| `services/audio_policy/` | 音频策略服务及其构建包。 |
| `services/audio_policy/client/` | 策略客户端、代理、Stub 和管理器门面。 |
| `services/audio_policy/common/` | 策略公共定义和辅助代码。 |
| `services/audio_policy/etc/` | 策略服务配置和部署资源。 |
| `services/audio_policy/idl/` | 策略 IPC 接口和监听器 IDL。 |
| `services/audio_policy/server/` | 策略服务实现。 |
| `services/audio_policy/server/common/` | 策略服务公共工具。 |

| `services/audio_policy/server/service/` | 系统能力服务主线和服务组装。 |

| `services/audio_service/` | 音频流和音频服务器服务包。 |
| `services/audio_service/client/` | Renderer、Capturer、进程、管理器和服务客户端实现。 |
| `services/audio_service/common/` | 转换、缓冲区、故障诊断、限幅器和流辅助代码。 |
| `services/audio_service/etc/` | 音频服务配置和部署资源。 |
| `services/audio_service/idl/` | 标准音频服务 IPC 接口 IDL。 |
| `services/audio_service/server/` | 音频系统能力、流生命周期、端点、引擎、适配器和服务实现。 |
| `services/audio_service/test/` | 音频服务单元测试、示例、基准测试和集成测试。 |
| `services/audio_suite/` | 可选音频套件服务包。 |
| `services/audio_suite/client/` | 音频套件客户端 API 和配置。 |
| `services/audio_suite/test/` | 音频套件测试和测试资源。 |

## 重要根文件

| 文件 | 简要说明 |
| --- | --- |
| `bundle.json` | 组件元数据、系统能力、依赖、功能开关和构建组。 |
| `config.gni` | 音频框架功能开关和条件依赖配置。 |
| `audio_framework.versionscript` | 共享库符号导出策略。 |
| `sa_profile/BUILD.gn` | 系统能力配置包定义。 |
| `hisysevent.yaml` | 音频诊断和故障事件定义。 |
