# 音频安全与隐私

## 信任边界

- 应用到框架绑定。
- 原生客户端到系统能力代理。
- IPC 代理到服务端 Stub。
- 策略服务到音频流管理。
- 音频流管理到 HDI、PulseAudio、蓝牙、USB 和分布式设备适配器。
- 配置文件和插件加载边界。

## 必要控制

- 对麦克风、播放采集、特权用途、设备控制、音量控制、音效和系统操作执行调用方身份及权限校验。
- 校验所有序列化输入、字符串、枚举、长度、会话标识、UID、PID、令牌 ID 和远程对象。
- 跨服务调用时正确保存和恢复 IPC 调用身份。
- 音频数据使用有界缓冲区和安全内存操作。
- 服务死亡和回调注销过程中不能产生悬空对象、重复回调或过期状态。
- 日志不能包含原始 PCM、麦克风数据、设备地址、网络标识和令牌值。

## 隐私敏感功能

- 麦克风静音和设备封锁状态。
- 播放采集过滤条件和用户选择。
- 唤醒源和虚拟采集源。
- 分布式音频路由。
- 音频转储和 PCM 诊断文件。
- 账户相关音量、路由和偏好状态。

## 失败策略

当无法确认权限、输入合法性、设备可用性或服务可用性时，应拒绝新的未授权操作并返回明确的错误。无效请求不得意外改变已有流和会话；权限撤销、隐私限制或设备失效影响活动会话时，应按策略停止、静音或迁移，不能继续沿用失效授权或资源。
