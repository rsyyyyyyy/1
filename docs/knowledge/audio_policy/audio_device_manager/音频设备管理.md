# 音频设备管理

## 范围

音频设备管理负责设备发现、描述、能力状态、连接生命周期和变化通知，覆盖输入输出设备、本地和分布式设备，以及蓝牙、USB、有线等接入类别。

## 设计规格

- 维护设备类别、角色、可用能力、连接状态和受控属性。
- 响应连接、断开、能力变化、策略变化和服务恢复事件，并向策略与流执行层发布状态。
- 对设备状态进行生命周期管理，确保断开设备不再被新会话使用，既有会话进入受控迁移或停止流程。
- 设备描述和能力来自实际适配及系统策略；具体设备能力可因产品和构建条件不同。

## 约束与常见误区

- 设备管理说明设备“是什么、是否可用”；设备选择和场景路由规则由独立策略模块负责。
- 设备连接不等于已成为活动设备；设备可用也不代表所有流格式都兼容。
- 热插拔事件可能重复、过期或乱序，处理时应校验当前设备状态并避免重复资源释放。
- 分布式设备需区分本地和远端身份、授权及生命周期。
- 蓝牙、USB、有线和虚拟设备不能被假设为拥有完全相同的能力或恢复行为。

## 安全与隐私

- 设备地址、网络标识和账户偏好属于敏感信息，应限制访问和诊断输出。
- 远端设备操作需验证授权和当前可信状态。
- 输入设备封锁、隐私状态和设备能力必须在实际采集或输出前再次确认。
