# 音频录制

## 范围

音频录制包括 Capturer 创建、输入设备选择、麦克风状态、采集缓冲区、回调和读取模式、播放采集、唤醒源以及隐私确认。

## 功能规格

- 根据采集源、格式、采样率、声道数、编码方式和输入设备要求创建并配置 Capturer。
- 支持阻塞读取、非阻塞读取、回调采集、刷新、暂停、停止、释放、位置、时延和溢出统计。
- 在功能开关允许时支持麦克风、远端、播放采集、唤醒和虚拟采集路径。
- 通知状态、设备、位置、周期、错误和服务死亡变化。

## 约束

- 麦克风和播放采集流必须经过采集源和策略校验。
- 校验读取长度、缓冲区生命周期、阻塞模式、流状态和会话标识。
- 采集源变化后不能暴露旧采集源残留数据。
- 溢出和隐私拒绝必须通过稳定的错误码或状态对调用方可见。

## 安全与隐私

- 麦克风访问必须遵守权限、隐私开关、设备封锁状态、账户状态和系统策略。
- 播放采集必须执行用途/PID 过滤以及用户选择结果。
- 禁止记录原始麦克风数据、采集缓冲区、设备地址和敏感应用身份。
- 策略要求停止或静音采集时，不能继续在后台隐式采集。
