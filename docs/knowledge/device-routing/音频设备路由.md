# 音频设备路由

## 范围

音频设备路由包括本地和分布式设备、输入输出设备、目标设备、活动路由、蓝牙、USB、有线设备、设备亲和性、热插拔和路由恢复。

## 功能规格

- 枚举输入输出设备及其能力。
- 根据流、应用、UID 或分布式网络选择目标输入输出设备。
- 响应设备连接、断开、配置变化、蓝牙协议、USB、有线和分布式设备事件。
- 根据流用途、设备角色、设备类型、场景、隐私、亲和性和产品策略进行路由。
- 设备变化或服务恢复后重建或恢复活动会话。

## 约束

- 不能选择已断开、被封锁或能力不匹配的设备。
- 路由变化必须与流状态变化串行协调。
- 用户选择的路由只有在合法条件持续满足时才能保留。
- 必须区分本地网络标识和远端网络标识。
- 设备能力配置和策略 XML 缺失或格式错误时，不能导致服务异常退出。

## 安全与隐私

- 保护设备地址、网络标识和账户相关偏好。
- 远端路由必须先完成分布式设备授权。
- 普通应用不能强制切换到系统特权设备。
- 麦克风输入选择必须遵守设备封锁和隐私状态。
